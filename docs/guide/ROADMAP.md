## 🚀 향후 계획 (Next Steps)

### New Architecture 지원 (JSI/Fabric)
- 현재 Old Architecture 기반인 플러그인을 TurboModules 및 Fabric Renderer를 지원하도록 업그레이드할 예정입니다. (현재 JSI Spec 작성 완료 단계)

### Expo Config Plugin 제공
- Expo 사용자들이 `app.json` 설정만으로 네이티브 권한 및 리포지토리를 자동 설정할 수 있도록 Config Plugin을 개발할 예정입니다.

### 추가 미디에이션 어댑터 확장
- 현재 지원 중인 네트워크 외에 추가적인 광고 네트워크 어댑터 지원을 지속적으로 확대할 계획입니다.

### 비즈보드(Bizboard) 전용 컴포넌트
- 카카오 애드핏 비즈보드 단독 지면 등에 최적화된 전용 UI 컴포넌트 추가를 검토 중입니다.
