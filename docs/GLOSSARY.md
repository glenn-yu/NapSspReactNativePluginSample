# Glossary (용어 사전)

`react-native-nap-ssp` 및 나스미디어 광고 SDK 사용 시 등장하는 주요 용어에 대한 설명입니다.

---

## 1. 식별자 (Identifiers)

### MediaKey (미디어 키)
- 나스미디어에서 매체사(앱) 단위로 발급하는 고유 키입니다.
- SDK 초기화(`initialize`) 시 필수적으로 사용됩니다.

### AdUnitId (광고 단위 ID)
- 앱 내의 개별 광고 지면(배너, 전면 등)을 식별하기 위한 고유 ID입니다.
- 한 앱에 여러 개의 광고 지면이 있을 수 있으며, 각 포맷에 맞는 ID를 사용해야 합니다.

---

## 2. 광고 포맷 (Ad Formats)

### Banner (배너)
- 화면의 일정 영역을 차지하는 띠 형태의 광고입니다.

### Interstitial (전면)
- 화면 전체를 덮는 광고로, 주로 페이지 전환이나 게임 스테이지 종료 시 노출됩니다.

### Rewarded (리워드)
- 동영상 광고 시청 완료 시 사용자에게 게임 아이템이나 포인트 등 보상을 지급하는 포맷입니다.

### Native (네이티브)
- 앱의 디자인과 일질감 없이 어우러지도록 구성 요소(제목, 이미지 등)를 직접 배치하는 광고입니다.

---

## 3. 기술 용어 (Technical Terms)

### Mediation (미디에이션)
- 여러 광고 네트워크(나스미디어, Google, Kakao 등)를 하나의 SDK로 관리하고, 수익이 가장 높은 광고를 우선적으로 노출하는 기술입니다.

### Impression (임프레션 / 노출)
- 광고가 실제 사용자 화면에 노출된 횟수를 의미합니다. 수익 집계의 핵심 기준이 됩니다.

### S2S (Server-to-Server) Callback
- 리워드 광고 시청 완료 시, 나스미디어 서버가 매체사 서버로 직접 보상 정보를 전송하는 방식입니다. 보안상 가장 권장되는 보상 검증 방법입니다.

### Fill Rate (필 레이트)
- 광고 요청 대비 실제 광고가 전달되어 노출된 비율입니다.
