# nap_ssp React Native Plugin — Summary

This repository contains the NapSsp React Native plugin sample and the original plan document.

Key points:
- Plugin exposes native nap ssp Android/iOS SDK to React Native via Native Modules/Native Views and supports New Architecture (JSI/Fabric) in later phases.
- Priorities: Banner and Interstitial (Phase1), Native and Rewarded (Phase2), Video/BizBoard (Phase3).
- See nap_ssp_plan.txt for full converted text from the original docx.
